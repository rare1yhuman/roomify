# Roomify

Roomify turns 2D floor plans into top-down 3D architectural renders using AI.

## Tech stack

- React
- TypeScript
- React Router
- Tailwind CSS
- Puter.js

## Run locally

```bash
git clone https://github.com/rare1yhuman/roomify.git
cd roomify
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.
